# tradevision-ai
TradeVision AI is a screen-based trading chart analysis assistant built for educational use.

## Features
- Screen-sharing workflow with explicit user permission
- Binary Options and Forex modes
- Local chart recognition quality scoring
- Signal generation engine with evidence and invalidation logic
- REST API for analysis data
- Unit tests for chart structure and signal logic

## Scripts
- npm install
- npm run dev
- npm run build
- npm run test

## Security notes
This project is for analysis and education only. It does not execute trades or connect to broker APIs.
